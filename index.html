Template from a link

Paste an Instagram, YouTube or Facebook video link. The backend reads the editing style of that video (colours, type, captions, pace) and saves it as a template.

This page is opened as a file, so the browser sends no usable origin and the API will block it. Open it through http://localhost:5180 instead (run python -m http.server 5180 in this folder).
